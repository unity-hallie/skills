# skills

Claude Code skills, kept in one place so they can be versioned and shared.

Each lives in `skills/<name>/SKILL.md`.

## Install

Symlink the ones you want into your global skills directory:

```bash
ln -s ~/repos/skills/skills/plain-signal ~/.claude/skills/plain-signal
```

## Skills

- **plain-signal** — keep replies short, because length costs the reader. Quaker plain
  speech meeting a control-loop argument: the reader's attention is the channel, and
  over-transmitting breaks their ability to steer.
